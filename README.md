Este projeto implementa um jogo de memória no microcontrolador 8051, utilizando a linguagem Assembly e a plataforma de simulação Edsim51.
O jogo consiste em acender uma sequência de LEDs, que o jogador deve memorizar e repetir corretamente usando um teclado matricial. A cada acerto, a sequência é aumentada, elevando a dificuldade. Se o jogador errar, a sequência é reiniciada e um aviso sonoro ou visual é exibido.
Este projeto foi desenvolvido como parte da disciplina de Arquitetura de Computadores do curso de Ciência da Computação da FEI.
